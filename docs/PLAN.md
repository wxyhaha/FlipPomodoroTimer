## 构建配置

使用 Arduino CLI 1.5.1、`esp32:esp32@3.3.11`，目标 `esp32:esp32:esp32s3`，Flash 16MB、OPI PSRAM，仓库本地依赖通过 `--libraries firmware/libraries` 指定。完整命令与 Wi-Fi 本地配置说明见[项目首页](../README.md)。

公开分发二进制之前，应在不含 `WiFiConfig.local.h` 的环境构建；项目许可证、第三方库与字库许可、干净环境复现仍需另行核实。
