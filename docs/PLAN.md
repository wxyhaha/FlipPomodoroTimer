# 开发与复现计划

## 开发方式与技术架构

本项目遵循“**底层硬件全打通 $\to$ 核心状态机 $\to$ 传感器手势闭环 $\to$ 低功耗与外壳装配**”的循序渐进路径。
固件采用纯命令行工具链（`arduino-cli v1.5.1` + `esp32:esp32@3.3.11`），消除对庞大图形 IDE 的环境依赖，确保任何开发者均可快速一键复现。

## 翻面计时规则设计（已实机落地版本）

结合 QMI8658 的 $(a_x, a_y, a_z)$ 重力加速度向量分布，已实现完整的四面独立倒计时、向后翻转暂停与自适应屏幕旋转手势状态机：

- **向后翻平（Backward Pause，`az <= -0.50g`）**：将设备向后推倒平放于桌面（屏幕朝上仰卧桌面），立即自动暂停倒计时，并保持 100% 满血点亮屏幕，显示暂停状态和当前剩余时间；新版已移除轮数显示；立回原面自动播放开始和弦音恢复倒计时。
- **四面侧立倒计时与自适应重力屏幕旋转**：无论设备以哪一个边缘作为底边立在桌面上，屏幕均自动在硬件层面无缝旋转，确保内容永远正向直立朝向用户：
  - **面三（下边着台，`ay > +0.35g`）**：30 分钟（标准番茄钟深度专注）。屏幕旋转 0（正向 0°），立起此面播放清脆和弦音并开始 30 分钟倒计时。
  - **面二（左边着台，`ax < -0.35g`）**：10 分钟（快速任务 / 敏捷冲刺）。屏幕旋转 1（顺时针 90°），立起此面播放清脆和弦音并开始 10 分钟倒计时。
  - **面一（上边着台，`ay < -0.35g`）**：5 分钟（短休息 / 闪电番茄）。屏幕旋转 2（倒置 180°），立起此面播放清脆和弦音并开始 5 分钟倒计时。
  - **面四（右边着台，`ax > +0.35g`）**：60 分钟（深度学习 / 长程专注）。屏幕旋转 3（顺时针 270°），立起此面播放清脆和弦音并开始 60 分钟倒计时。
- **翻转完全盖下（Screen Down，`az >= +0.50g`）**：将开发板屏幕向下扣在桌面上，自动暂停当前倒计时，并拉高 GPIO 4 关闭背光（完全熄屏），实现零光害极低功耗静默待机。
- **拿取与平放防抖**：在向后翻平桌面或拿取移动过程中，平放时保持前一方向；侧立方向使用 100ms 确认与轴向迟滞；计时姿态事件保留 600ms 防抖，两者分开处理。
- **轻触 / 按键干预**：番茄钟页非模式按钮区域轻触或单击 BOOT 可暂停/继续；时钟页空白触摸无动作。
- **长按复位**：长按板载 BOOT 键 $\ge 1.5$ 秒，安全复位当前计时器。
- **倒计时归零**：倒计时结束时，触发高分贝三连音和弦警报，显示完成勾选标记；新版不使用徽章呼吸闪烁。
