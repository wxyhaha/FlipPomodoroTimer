# 开发与复现计划

## 开发方式与技术架构

本项目遵循“**底层硬件全打通 $\to$ 核心状态机 $\to$ 传感器手势闭环 $\to$ 低功耗与外壳装配**”的循序渐进路径。
固件采用纯命令行工具链（`arduino-cli v1.5.1` + `esp32:esp32@3.3.11`），消除对庞大图形 IDE 的环境依赖，确保任何开发者均可快速一键复现。

## 翻面计时规则设计与演进

### 当前已实现版本（v1.0 经典桌面翻转）

- **正面朝上平放（Screen Up）**：屏幕点亮，显示 480×480 大字倒计时与环形进度条，专注计时平稳运行。
- **轻触 / 按键干预**：轻触屏幕任意区域或单击板载 BOOT 键，可随时手动暂停或继续。
- **长按复位**：长按板载 BOOT 键 $\ge 1.5$ 秒，安全复位回初始 25 分钟准备状态。
- **翻转朝下盖下（Screen Down）**：将开发板面朝桌面盖下，自动触发 `PAUSE_BY_FLIP` 并拉低 GPIO 4 关闭背光，进入极低功耗静默保持状态，不浪费电量与专注时间。
- **翻回正面唤醒（Screen Up Resume）**：重新翻回正面，背光自动点亮，倒计时精准无缝继续，无需多余触摸确认。
- **防抖机制**：600ms 连续姿态稳定过滤，拿起移动或轻微敲桌不会产生误触发。

### 后续规划版本（v2.0 多面独立倾角计时面）

结合后续 3D 打印外壳，将利用 QMI8658 的 $(a_x, a_y)$ 倾角区分 4 个不同侧倾摆放姿态：
- **正面 1（朝前倾）**：5 分钟短休息 / 闪电番茄
- **正面 2（朝左倾）**：15 分钟长休息 / 敏捷任务
- **正面 3（朝后倾）**：25 分钟标准番茄钟专注
- **正面 4（朝右倾）**：45 分钟深度学习与长程专注
- **翻转完全盖下**：统一保持为“暂停当前倒计时并息屏”。

## 固件调试与复现命令速查

| 操作 | 对应命令 |
| :--- | :--- |
| **编译固件** | `arduino-cli compile --libraries firmware/libraries --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi" firmware/FlipPomodoroTimer` |
| **烧录固件** | `arduino-cli upload -p COM3 --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi" firmware/FlipPomodoroTimer` |
| **串口监听** | `python -c "import serial; ser=serial.Serial('COM3', 115200); [print(ser.readline().decode('utf-8', errors='replace').strip()) for _ in iter(int, 1)]"` |
