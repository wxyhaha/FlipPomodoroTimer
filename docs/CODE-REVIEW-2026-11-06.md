# 固件检查与当前限制

固件实现已覆盖计时状态（专注/休息闭环）、电源与 PWM 背光、触摸、显示（双缓冲超时自恢复）、音频（音量可调）、NVS 配置与专注统计、Web 控制台配网以及异步 NTP 校时的主要交互；当前功能及实际验证范围见[功能状态与验收说明](UI-V6-VALIDATION.md)。

已改进项：已将 `ExpanderLock` 升级为全局递归 `I2CLock` 覆盖全链路共享 I2C 访问；已补充 RTC 日期时间合理性校验；已为 `FramePresenter` 增加帧超时自动跳过与恢复机制。

仍需注意：充电电流、完整充电周期、熄屏降频后的实际续航尚未实测；最新固件已完成编译验证，但 Web 控制台、异步校时、PWM 背光及并发场景仍需在完整设备上进一步实机测试。编译通过不等同于所有实机场景均已通过。
