# 功能状态与验收说明

## 当前界面与交互

- 番茄钟显示 20 段彩色剩余时间环、倒计时和当前时间；时钟页支持右下角一键切换两款主题（并可在 Web 控制台配置）：
  - **极简天象时钟**：大号时分（`y=165` 上下居中，带微阴影、冒号常亮）、小秒数、中文日期与星期，搭配 24 小时昼夜平滑渐变背景（4×4 Bayer 有序抖动消除 RGB565 色带，32-bit 顺序写入优化）、在时间数字上方（`y=64..148`，可自然穿过顶部状态栏背后）升降的精致日轮（临边昏暗 + 内日冕微芒，按晨昏暖度缓存）与 3D 精致月相（含月海暗斑、球面光照、临边昏暗、地球照与双层月晕，精灵缓存）、底部三层分形雾化山脉（含山脊天光高光）、QMI8658 陀螺仪视差景深（收敛后自动退回 1fps）、深夜微闪星点与偶发流星，整点触发星光涟漪动效；
  - **像素小猫 · 全屏时间小世界**：120×120 逻辑像素 ×4 全屏放大，采用无遮挡全景大落地窗（带束腰弧形窗帘）将带深色描边的圆润粗体像素时间（冒号常亮）与居中四向描边中文日期融入房间场景，包含 4 时段作息小猫（深棕黑框圆眼镜）、清晨/白天斜射暖阳光束、复古菱形暗纹编织小地毯与陶瓷水碗、与今日专注次数联动的窗台成长小盆栽及点击摸摸头爱心反馈；
  - 时钟页支持点击时间数字开启 **24H 昼夜实机演示模式**（串口支持 `DEMO_DAY`），以及整点报时仪式（亮屏且 RTC 时间有效时触发，22:00–07:00 夜间自动免打扰仅播视觉动效，可在 Web 控制台开关）。
- 四个侧面（面一至面四）默认分别为 5 / 10 / 60 / 30 分钟（支持 Web 控制台自定义）；翻面 100ms~600ms 缓冲期显示目标面预览，显示方向随姿态旋转。历史演示视频拍摄于面三为 30 分钟、面四为 60 分钟时期。
- 触摸或 BOOT 控制计时；专注完成后点击屏幕或短按 BOOT 可进入休息倒计时（可配置），休息完成后重新开始当前面专注。屏幕已息时，首次操作只唤醒。
- 完成后默认 30 秒无操作自动息屏（可配置），期间每 15 秒轻柔重响一次（最多 3 次）；屏幕朝下在自由模式下自动暂停并息屏，在日程模式下仅息屏不暂停。已移除各页左下角手动息屏按钮，番茄钟页与时钟页左下角改为「自由模式 ⇄ 日程模式」切换按钮。
- 新增每日日程模式（`ScheduleManager.h`）：进入日程模式后锁定在番茄钟页，除非点击左下角退出日程模式，否则不可切换至时钟/统计页（USB 插入亦不切页），且计时不可暂停或长按重置；若在时钟页通过左下角按钮切换进入日程模式且当前处于某日程时段，会在时钟页弹出确认弹窗（显示「点击按钮或短按 BOOT 开始」提示），点击「确定开始」（或短按 BOOT）或「跳过本次」后立即跳转到番茄钟页，确认后按 `endSec - nowSec` 严格对齐时间表结束点倒计时。弹窗提醒使用短促的 `playStartTone()`（~1.1s），`AudioManager` 播放任务优先级为 4；为保持页面渲染流畅，已移除离线语音识别（`VoiceCmdManager` / ES7210 + ESP-SR）及 `model` 分区依赖。内置 07:30–23:30 共 26 条默认作息/学习时间表（上限 32 条，禁止 0 分钟条目，NVS 持久化，可在 Web 控制台编辑与恢复默认）；日程模式下向后翻平不暂停、左右侧翻只旋转屏幕不覆盖时长，仅「专注」分类条目计入统计。
- 顶部显示沙漏 / 统计 / 时钟三页切换入口、电量估算百分比、低电量颜色、充电闪电与后台 NTP 同步指示点；未接电池或数据无效显示 `--%`。
- 新增统计页（`UI_MODE_STATS`）：展示今日与历史累计番茄数/专注分钟数、近 7 日专注柱状图，右上角提供 5 款番茄钟表盘主题（科技环 / Fliqlo 翻页 / IN-18 辉光管 / 像素番茄 / 流沙沙漏）快捷切换按钮，底部提供一键开关 Web 控制台的触控按钮（优先连接已存 Wi-Fi 局域网访问，未配置或连接超时自动回退 `FlipPomodoro-Setup` 热点）。
- USB 接入时若正在计时，保留当前页面并继续；非运行状态接入切时钟页。拔线切番茄钟页，待机时按稳定侧面自动开始；其他计时状态保持。

## 实现要点

显示使用驱动双帧缓冲、20 行 Bounce Buffer（16MHz PCLK，在 20 行 Bounce Buffer 抗 DMA 欠载基础上将刷新率从 37.6Hz 提升至约 50.1Hz 以消除细微频闪）、局部更新与帧释放回调，并在超时时支持自动跳过与恢复；圆环扇区索引在启动时预计算以消除渲染期 `atan2f` 运算，数字绘制直接写入帧缓冲。背光改用 LEDC 20kHz PWM 调光，熄屏且无热点/同步任务时停止渲染并降频至 80MHz。所有共享 I2C 总线访问均由递归互斥锁 `I2CLock` 保护；配置与近 7 日统计持久化在 NVS `Preferences` 中；Wi-Fi / NTP 校时改为后台异步任务。提示音由后台任务播放，见[提示音说明](AUDIO.md)。

## 已完成的观察与待验证内容

- 已提供实物照片和 20 秒演示视频，可在[项目首页](../README.md)查看；照片显示设备已装入外壳，视频可见计时切面、旋转和时钟页切换（拍摄于早期固件版本）。
- 最新固件已通过 `arduino-cli` 完整编译（`PartitionScheme=app3M_fat9M_16MB`，Sketch 占 `2,328,554` bytes / `74%` Flash，全局变量占 `97,908` bytes / `29%` 动态内存）并已烧录至 `COM3` 通过写入校验，当前界面观感与流畅度待实机确认。此前固件曾在实机上观察确认「极简天象时钟」午后昼夜渐变（4×4 Bayer 抖动）与三层分形山脉的显示效果，以及 `16 MHz` PCLK + `20 kHz` PWM 改善频闪的效果。
- 电池可短时独立供电；一次 USB 接入观察中，系统运行且电源芯片连续 35 秒报告充电。实际电流、完整充电周期、容量、温升、80MHz 熄屏功耗与续航未测。
