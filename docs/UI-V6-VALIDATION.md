# 功能状态与验收说明

## 当前界面与交互

- 番茄钟显示 20 段彩色剩余时间环、倒计时和当前时间；时钟页显示大号时分、小秒数、中文日期与星期。
- 四个侧面分别为 5 / 10 / 30 / 60 分钟；显示方向随姿态旋转。用户提供的视频展示翻面切换和页面切换。
- 触摸或 BOOT 控制计时；计时完成后点击番茄钟页空白区域立即按当前面重开。屏幕已息时，首次操作只唤醒。
- 完成后 30 秒无操作自动息屏；手动息屏不改变计时，屏幕朝下则自动暂停并息屏。
- 顶部显示电量估算百分比、低电量颜色与充电闪电；未接电池或数据无效显示 `--%`。
- USB 接入时若正在计时，保留当前页面并继续；非运行状态接入切时钟页。拔线切番茄钟页，待机时按稳定侧面自动开始；其他计时状态保持。

## 实现要点

显示使用驱动双帧缓冲、局部更新与帧释放回调；旋转优先使用 240×240 内部 RAM 纹理并点采样，最终落位恢复原生分辨率。视觉方向与计时面分别使用 100ms 和 600ms 稳定判断。提示音由后台任务播放，见[提示音说明](AUDIO.md)。

## 已完成的观察与待验证内容

- 已提供实物照片和 20 秒演示视频，可在[项目首页](../README.md)查看；照片显示设备已装入外壳，视频可见计时切面、旋转和时钟页切换。
- 当前固件曾编译并烧录，写入校验通过；USB 插拔相关状态机在主机模拟中通过，不能代替实物插拔测试。
- 电池可短时独立供电；一次 USB 接入观察中，系统运行且电源芯片连续 35 秒报告充电。实际电流、完整充电周期、容量、温升与续航未测。
- 最新的电量图标、USB 插拔、完成后重启、自动息屏、PWRKEY 双击、动画清晰度和流畅度仍需按实际使用场景逐项确认；已提供的视频不覆盖所有这些场景。
- 外壳已有实物装配，长期防脱、线束受力、反复拆装和材料耐久尚未验证。模型尺寸为名义值。
