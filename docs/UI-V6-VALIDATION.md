# 功能状态与验收说明

## 当前界面与交互

- 番茄钟显示 20 段彩色剩余时间环、倒计时和当前时间；时钟页支持右下角一键切换两款主题（并可在 Web 控制台配置）：
  - **极简天象时钟**：大号时分（带微阴影与冒号呼吸）、小秒数、中文日期与星期，搭配 24 小时昼夜平滑渐变背景（4×4 Bayer 有序抖动消除 RGB565 色带）、真实日月轨迹与实时月相、底部三层分形雾化山脉（含山脊天光高光）、QMI8658 陀螺仪视差景深、深夜微闪星点与偶发流星，整点触发星光涟漪动效；
  - **像素小猫 · 全屏时间小世界**：120×120 逻辑像素 ×4 全屏放大，采用全景大落地窗将圆润粗体像素时间、日期与迷你小番茄专注计数融入房间场景，包含 4 时段作息小猫（深棕黑框圆眼镜）、清晨/白天斜射暖阳光束、暖色编织小地毯、与今日专注次数联动的窗台成长小盆栽、点击摸摸头爱心反馈及基于 QMI8658 倾斜角滚动的地板毛线球；
  - 时钟页支持点击时间数字开启 **24H 昼夜实机演示模式**（串口支持 `DEMO_DAY`），以及整点报时仪式（亮屏且 RTC 时间有效时触发，22:00–07:00 夜间自动免打扰仅播视觉动效，可在 Web 控制台开关）。
- 四个侧面（面一至面四）默认分别为 5 / 10 / 60 / 30 分钟（支持 Web 控制台自定义）；翻面 100ms~600ms 缓冲期显示目标面预览，显示方向随姿态旋转。历史演示视频拍摄于面三为 30 分钟、面四为 60 分钟时期。
- 触摸或 BOOT 控制计时；专注完成后点击屏幕或短按 BOOT 可进入休息倒计时（可配置），休息完成后重新开始当前面专注。屏幕已息时，首次操作只唤醒。
- 完成后默认 30 秒无操作自动息屏（可配置），期间每 15 秒轻柔重响一次（最多 3 次）；手动息屏不改变计时，屏幕朝下则自动暂停并息屏。
- 顶部显示沙漏 / 统计 / 时钟三页切换入口、电量估算百分比、低电量颜色、充电闪电与后台 NTP 同步指示点；未接电池或数据无效显示 `--%`。
- 新增统计页（`UI_MODE_STATS`）：展示今日与历史累计番茄数/专注分钟数、近 7 日专注柱状图，右上角提供 5 款番茄钟表盘主题（科技环 / Fliqlo 翻页 / IN-18 辉光管 / 像素番茄 / 流沙沙漏）快捷切换按钮，底部提供一键开关 Web 控制台的触控按钮（优先连接已存 Wi-Fi 局域网访问，未配置或连接超时自动回退 `FlipPomodoro-Setup` 热点）。
- USB 接入时若正在计时，保留当前页面并继续；非运行状态接入切时钟页。拔线切番茄钟页，待机时按稳定侧面自动开始；其他计时状态保持。

## 实现要点

显示使用驱动双帧缓冲、局部更新与帧释放回调，并在超时时支持自动跳过与恢复；圆环扇区索引在启动时预计算以消除渲染期 `atan2f` 运算，数字绘制直接写入帧缓冲。背光改用 LEDC 5kHz PWM 调光，熄屏且无热点/同步任务时停止渲染并降频至 80MHz。所有共享 I2C 总线访问均由递归互斥锁 `I2CLock` 保护；配置与近 7 日统计持久化在 NVS `Preferences` 中；Wi-Fi / NTP 校时改为后台异步任务。提示音由后台任务播放，见[提示音说明](AUDIO.md)。

## 已完成的观察与待验证内容

- 已提供实物照片和 20 秒演示视频，可在[项目首页](../README.md)查看；照片显示设备已装入外壳，视频可见计时切面、旋转和时钟页切换（拍摄于早期固件版本）。
- 最新固件已通过 `arduino-cli` 完整编译（ESP32-S3, 16MB Flash, OPI PSRAM）、烧录至 `COM3` 并通过写入校验；已在实机上观察确认「极简天象时钟」午后昼夜渐变（4×4 Bayer 抖动）与三层分形山脉的显示效果。
- 电池可短时独立供电；一次 USB 接入观察中，系统运行且电源芯片连续 35 秒报告充电。实际电流、完整充电周期、容量、温升、80MHz 熄屏功耗与续航未测。
- 以下新增或调整项均待进一步实机验收：极简天象日月升落与月相计算、QMI8658 陀螺仪视差、24H 演示模式完整循环、「像素小猫 · 时间小世界」全时段（清晨/白天/黄昏/深夜）切换、摸摸头互动与音效、毛线球倾斜物理、整点报时与夜间免打扰、Web 控制台新配置项（`cthm` / `hchm`），以及 PWM 多级背光调光、80MHz 低功耗模式与 RGB 屏幕唤醒一致性、异步 NTP 校时、Web 控制台 AP 配网与 Captive Portal、统计页与 NVS 持久化、休息态流程及完成态呼吸/重复提醒。
- 外壳已有实物装配，长期防脱、线束受力、反复拆装和材料耐久尚未验证。模型尺寸为名义值。
