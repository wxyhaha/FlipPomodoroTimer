# V6 / V6.1：清晰字形、稳定刷新与二维旋转

## 改动依据

用户实拍反馈 V5 主体偏小、数字发虚、每秒更新闪动、翻面直接跳方向。本轮保留双页和 20 段四主色环，重点调整显示管线。

## V6.1 动画性能优化

用户实机反馈：V6 已不再闪动，数字显示正常，但旋转动画明显卡顿。该反馈确认了静态显示的改善，不能视为动画验收通过。

V6.1 保留静态布局和原生字形，只优化动画及缓冲交接：

- 使用 SDK 的 `on_frame_buf_complete` 回调确认旧帧源可以复用，替代固定等待两次 VSYNC。当前固定启用 bounce buffer；该模式下驱动在换源后发出完成事件。不退回无同步写前缓冲。
- 中间动画帧完整覆盖后台缓冲，不再在每帧之后额外镜像整屏。动画结束时提交完整原生画面并恢复两缓冲一致，之后继续正常的局部数字更新。
- 动画开始时生成临时小纹理：优先使用 240×240 内部 RAM，内存不足时尝试 160×160 / 120×120，保留约 48KB 余量；必要时退回 240×240 PSRAM。中间帧用较少采样点旋转和块复制，结束后恢复完整 480×480 原生画面并释放纹理。临时纹理会降低运动中细节，不降低静止文字清晰度。
- 目标动画时长调为 240ms，取消 33ms 的额外帧间隔；动画期间主循环让出 1ms，实际提交仍受显示刷新和计算耗时限制。
- PMU 测量改为每 250ms 采样，避免动画每帧反复进行电池/供电 I2C 读取；不改变充电参数或硬件电源切换。
- 新增缓存位置、单帧渲染耗时、缓冲释放等待耗时、动画完成帧数与实际时长日志，使用实测数据判断改善，不承诺理论帧率。

## 当前实现规格

- 圆环外径 400px、内径 356px，中心约 (240,260)。有效显示区占宽从 75% 增加至约 83%，同时上移；顶部图标缩小，触摸热区仍保持 56×56px。
- 番茄钟主数字为 64×104px 的原生字形；时钟主数字 70×116px，小时间 24×40px，小秒数 23×39px。字形由原始几何在每个最终尺寸做 4×4 子像素采样，不再运行时放大低分辨率蒙版或插值。边缘保留窄抗锯齿带，小时间改为中性灰白。
- 静止时只重画变化的数字单元。当前时间按分钟更新，日期按日期变化更新，圆环在亮段数或暂停状态变化时更新，按钮和电量按模式/供电状态变化更新。切页和首次显示才完整合成。
- RGB 驱动启用两个驱动分配的完整帧缓冲，并使用两块 10 行内部 RAM bounce buffer。只写非扫描缓冲，提交后等待 SDK 帧源释放事件再复用旧缓冲（V6 初版曾等待两次 VSYNC）；旧缓冲只同步发生变化的物理区域。
- 新增 FramePresenter.h/.cpp 管理方向映射、局部提交、缓冲交接及诊断。若提交失败或 帧源释放等待超过 150ms，停止继续写显示缓冲并记录错误，避免不安全地退回前缓冲绘制。
- 方向变化加入目标 240ms 的二维旋转，smoothstep 缓入缓出，按最短方向过渡；快速连续翻面时从当前角度转向最新目标，不排队。只做平面旋转，不恢复透视压缩或变暗。动画帧使用定点反向采样，最后一帧回到整数方向映射和原生字形。
- 动画过程中冻结显示快照，状态机仍在主循环按单调时钟推进；每次提交等待刷新边界会短暂占用主循环，实际动画时长与帧数以串口记录为准，不宣称恒定帧率。
- 动画中忽略屏幕轻触，防止触摸移动的按钮；BOOT 操作仍有效。完成后使用最新时间/状态更新画面。

## 驱动修改与复现

仓库内 GFX Library for Arduino 的 Arduino_ESP32RGBPanel.h/.cpp 增加 opt-in `enableDoubleBuffer()`、只读 `panelHandle()` 及按需 `num_fbs=2`。默认仍为单缓冲，其他草图不自动改变。复现应使用仓库中的库，不能直接换成未包含此补丁的上游库。

接口核对依据为本地 ESP32 Arduino 3.3.11 SDK 头文件及 [Espressif RGB 驱动源代码](https://github.com/espressif/esp-idf/blob/v5.5.2/components/esp_lcd/rgb/esp_lcd_panel_rgb.c)。不修改系统安装的 SDK。

显示相关动态 PSRAM：驱动帧缓冲 921,600 字节、合成画布 460,800 字节、圆环缓存 326,432 字节，合计约 1.71MB；bounce buffer 另占约 19.2KB 内部 RAM。V6.1 动画期间临时纹理最多另占 115,200 字节内部 RAM（或 PSRAM 回退），结束后释放。字形数组位于固件只读数据区，不按静态 RAM 使用率推算完整运行内存。

生成字形：`python tools/generate_digit_font.py`，仅需 Python 3.10+ 标准库。生成后的 DigitFont.h 已纳入源码文件，无需在每次编译前重建。

```powershell
arduino-cli compile --jobs 6 --build-path build/arduino-v6 --fqbn esp32:esp32:esp32s3:CDCOnBoot=default,MSCOnBoot=default,DFUOnBoot=default,UploadMode=default,CPUFreq=240,FlashMode=qio,FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=opi,LoopCore=1,EventsCore=1,EraseFlash=none --libraries firmware/libraries --output-dir build/ui-v6 firmware/FlipPomodoroTimer
arduino-cli upload --port COM3 --fqbn esp32:esp32:esp32s3 --input-dir build/ui-v6 firmware/FlipPomodoroTimer
```

串口号按实际电脑替换。固定 build-path 用于后续增量构建；build 内产物和本地日志不提交。

## 实机人工验收

- 每秒数字更新时观察整屏、顶部和圆环，确认没有整体亮暗闪动；同时检查数字变化区域无残影或撕裂。
- 静止看主数字和小时间边缘，不用动画中瞬时画面判断最终字形清晰度。
- 四方向翻转有短旋转过渡，最终清晰且位置正确；快速连续翻面不排队、不持续抖动。
- 方向动画结束后两个图标均可准确点中，中文日期星期正常；换面重开、原面恢复和向后暂停保持正确。
- 检查圆环放大后未被按钮或屏幕边界裁切。

若仍出现亮度闪动或显示异常，需要结合实拍视频和同步诊断继续定位，不仅凭编译成功或零超时认定问题解决。
