# 最终界面

番茄钟页采用 20 段彩色时间环与自绘数码字（并支持 5 款切换主题）；时钟页提供「极简天象时钟」（大号时分、小秒数、中文日期星期配 24 小时 Bayer 抖动昼夜渐变、真实日月轨迹与实时月相、三层分形雾化山脉、陀螺仪视差、星空流星与整点光环）和「像素小猫 · 时间小世界」（120×120 逻辑像素 ×4 放大、4 时段作息、统计联动盆栽、触控摸摸头与倾斜毛线球）两款主题，并支持点击时间数字开启 24H 演示模式。顶部左右分别为番茄钟、统计和时钟入口，中间显示电池状态及百分比，左下角提供息屏入口，时钟页右下角提供时钟主题切换入口。

显示方向根据姿态旋转，静止状态使用局部刷新；动画使用较小纹理以兼顾性能，最终画面恢复原生分辨率。实际画面和操作请看[成品照片与演示](../../README.md)，具体验证边界见[功能状态与验收说明](../UI-V6-VALIDATION.md)。
