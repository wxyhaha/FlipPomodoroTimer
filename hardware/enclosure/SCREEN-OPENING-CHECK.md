# V12.8 屏幕开口核查

核对来源为微雪 [ESP32-S3-Touch-LCD-4B 官方产品尺寸图](https://docs.waveshare.net/assets/images/ESP32-S3-Touch-LCD-4B-details-size-10826e511c001d8541b2a98abc4337d6.webp)，来自[官方产品文档](https://docs.waveshare.net/ESP32-S3-Touch-LCD-4B/)。图中显示区域为 **71.93×71.93mm**，面板外形为86.50×86.50mm。本项目采用用户实测厚度14.5mm，区别于图示14.0mm；这不改变本次正面宽高核查。

当前前框前口78×78mm，最窄内口72.8×72.8mm，内口圆角半径0.8mm。显示区按居中放置，名义直边余量为每边0.435mm；四角的最小余量更小，不能只按直边宽度判断。

`check_screen_opening.py` 从导出的 `shell-assembly.stl` 读取真实网格，以整个71.93mm显示方形构造贯穿前框的视线体积，包含四角；分别检查正视、水平和垂直±15°/±30°，并组合X方向-0.05/0/+0.05mm、Z方向-0.2/0/+0.2mm对位偏移，总共81种情况。V12.8的9种正视对位场景均未发现开口遮挡；叠加±30°斜视的14种场景存在少量遮挡，其余场景通过。间隙放宽使上下活动范围增加，而按用户“只改间隙”的要求保留原开口，因此不能声称81种场景全部无挡，结果和所检查STL的SHA-256保存在 `v12/screen-check.json`。每次重新生成STL后自动执行，打印包也包含该结果。

这项结果仅确认所检对位偏移下的正视可视范围；斜视遮边是当前已知限制，并非全角度无遮挡或实物打印装配保证：

- 官方尺寸图没有单独标注显示区相对外框的偏移，本模型假定居中。
- 视线从面板前表面出发，未包含实际显示层相对盖板的深度、折射和实物触控玻璃。
- 水平±0.05mm偏移是核查的场景；右侧仍未机械锁定，不能保证实际面板不会往右偏得更多。
- 打印收缩、毛边、支撑残留可能使开口变小。清理后需对位实物，不能用挤压玻璃的方式修配。

建议先将 `screen-opening-template.svg` 以100%实际尺寸打印，核对50mm校验线，沿72.8mm圆角开口线剪开并对照点亮的屏幕白色边框。确认四边和四角完整可见，再让商家打印大外壳。模板可帮助检查对位；它不代替前框3mm深度的实物斜视检查。

单独重跑：

```powershell
.\.venv-cad\Scripts\python.exe hardware/enclosure/check_screen_opening.py
```
