# V12.9 代打印与装配说明

最新下单请使用 `v12.9/V12.9-shell.stl`、`V12.9-lid.stl`、`V12.9-retainer.stl`，各1件。详细尺寸汇总见[最终核对表](FINAL-DIMENSIONS-V12.9.md)。源码输出的 v12/*-print.stl 与其同几何，不要重复下单。

V12.9仅改两个前舌与对应卡口：舌片伸出立臂3mm，穿过2mm挡边后露出1mm；通孔宽6.6mm、高2.4mm，舌宽6mm、厚1.2mm，上沿间隙0.2mm、下方1mm为倾斜装拆让位。其余几何与V12.8对比未改变，后盖不变。拆装需先移开后盖和面板，松压条螺丝后逐渐倾斜后退；不是平移硬拉。按圆柱电池包络采样的拆装路径通过，实物仍未验证。

V12.8 只放宽面板上下、前后间隙至每侧0.2mm；槽高86.90mm、入口深14.90mm，后导轨位置随之后移。保留原四螺丝后盖（加电池压条两颗，共六颗），没有采用讨论过的滑盖或单螺丝方案。左侧两段止挡与3mm内缩沿用；左止挡侧向间隙仍为0.05mm，后盖定位边间隙仍为0.3mm。

屏幕开口已按官方71.93×71.93mm核查；最窄开口72.8mm。放宽间隙后，9种正视对位场景通过；81种总场景中的14种极限偏移叠加30°斜视场景存在少量遮挡，开口按用户要求保持原样，见[核查说明](SCREEN-OPENING-CHECK.md)。官方图未单独标显示区偏移，当前按居中处理；请先用包内1:1模板核对实物。每次STL生成后自动重跑核查，结果记录所检STL的哈希。

V12.7 在面板背面上下沿各增加一条与主壳一体的导轨挡边，各搭住背壳边缘2mm、沿前后方向厚2mm，后侧间隙0.05mm。右端设置约0.3mm导入斜口；面板从右侧沿槽滑入并在左止挡处停止。背面中央仍开放。增加后移碰撞检查，确认挡边限制面板向电池仓倾倒；右侧退出路径仍未锁定。fit-panel-guide.stl 是实际右侧导轨的窄条截取试样，先用其试插，注意它同样可能需要支撑。

V12.6 按用户反馈取消左侧中央止挡，改成左上、左下两个短止挡，每处覆盖面板边缘4mm，与上下壳连成一体。左侧中间78.5mm完全留空，不在喇叭区域加挡条。保持只能从右侧插入，右端仍未锁定。

V12.5 将屏幕内缩从6mm改为3mm，窗口曲面同步变浅；左侧加与主壳一体的小止挡，挡住左侧插入及向左滑出路径。间隙仍为上下、前后各0.05mm。已检查就位无干涉、右侧三处插入位置无碰撞，向左移动0.2mm会被止挡拦住。右侧仍开放，不应把单侧止挡描述为双向锁定。

V12.4 将前后名义间隙均设为0.05mm，面板厚14.5mm、插入口深14.60mm；上下仍各0.05mm。前窗口挖空与面板槽同步调整并保留重叠，避免重新产生薄面。取消旧0.3mm胶条定位方案，右侧机械防脱尚未实现。

V12.1 修复了面板槽与后仓挖空区域仅在 Y=21.3mm 相接而留下薄面的错误：后仓挖空从 Y=21.1mm 起，与面板槽重叠0.2mm。原先的体积与封闭性检查没有查出残留面，因此新增九条穿过窗口的射线检查，确认打印壳体在前后通道中没有阻挡面。该阶段生成的 V12 打印包已留作版本记录；当前请使用 [V12.9 正式件目录](v12.9/)，避免误用历史几何。外部尺寸及其他装配结构沿用。

V12.2 按用户要求将面板上下间隙改为各0.05mm，槽高86.60mm。新增 fit-panel-slot.stl 高度配合试样；它是单独的 U 形量规，非总装零件。先用实际面板试插，确认后再打完整外壳。0.05mm为模型名义值，不代表代打机器能保证这一精度；仍需解决侧向机械防脱固定。

这是针对现有实测设备的首件试制版，已导出封闭 STL，可以交给商家切片打印。尚未实物试装，不等于已经量产定型。尺寸单位均为 **mm**，不得自动缩放；未生成任何打印机专用 G-code。

## 给商家的信息

用户选择嘉立创代打：可分别上传 `shell-print.stl`、`lid-print.stl`、`retainer-print.stl`，各1件，单位mm；无需上传装配GLB或assembly坐标版本，试样按需要单独下单。STL只提供几何，材料、工艺、颜色和数量仍需在下单页选择。[嘉立创官方须知](https://www.jlc.com/portal/q7i40026.html)支持STL，并公布100mm以内树脂常规精度±0.2mm，尼龙及工程塑料±0.3mm，实际取决于结构和材料。当前面板上下、前后每侧0.2mm是名义配合间隙，不能视为供应商保证可插入的配合；下大壳订单前应先试样或向厂家确认配合处理。

以下PETG与喷嘴/层高设置只针对FDM。若在嘉立创选择SLA树脂或尼龙工艺，应按该材料工艺评审，不套用FDM设置；压条有弹性舌片，2.5mm自攻导孔也需结合材料与实际螺丝试拧确认。模型不含螺丝等五金件，6颗自攻螺丝另行购买，规格见后文。

请使用 PETG，0.4mm 喷嘴、0.2mm 层高、至少 4 道壁、5 层顶底、20%～30% 填充作为首次切片起点。三件可使用同一种颜色；预览中的分色仅为说明结构。由商家按机器和耗材调整温度、速度、收缩与支撑参数。

建议先打印 fit-rail.stl 与 fit-tongue.stl，试长舌穿孔配合，再打印完整压条。fit-screws.stl 是 3 个导孔试样：长底座由左至右（X 增大）依次为 2.4、2.5、2.6mm；用实际准备购买的螺丝试拧。正式模型导孔为 2.5mm。如果试样不合适，应改模型重建，不能靠整体缩放解决孔位配合。

商家应确认无缺面、首层接触足够、内侧支撑可取出，并回传切片摆放与支撑预览。大壳首次只打一件。STL 本身为封闭网格，但网格检查不能代替切片和装配验证。

## 尺寸与结构

- 总装外包络为 **宽90.5 × 深94.5 × 高92.5mm**；主体深90.5mm、后盖外露4mm，整体接近正方体。
- 主壳一体包含前曲面边框、上下护边及后导轨挡边、后仓、托槽、压条后锚座和四个后盖螺丝座；后盖和电池压条分别打印。主壳外缘 R2mm，后盖 R1mm，保持侧面大平面。
- 目标面板 86.5×86.5×14.5mm，内缩3mm；侧插槽上下各留0.2mm（总高度86.90mm）；前框到面板前表面留0.2mm，侧口后缘到面板后表面为0.2mm，插入口深14.90mm。面板后方与电池仓连通，上下后挡边各搭入2mm形成导向槽，可限制前后位移，但不能阻止沿右侧退出，左上、左下各有一体止挡（宽1.95mm，各覆盖面板边缘4mm，与面板左缘留0.05mm）；中间78.5mm高的区域保持开放，避让喇叭，面板只能从右侧插入，按钮和 USB 不开独立孔。前开口78mm，向内平滑收至72.8mm。
- V12.4取消原先0.3mm厚的双面胶定位方案，它仍厚于当前0.2mm前侧间隙。**已增加左侧固定止挡，右侧仍没有可拆防脱件**；紧配合尺寸不等于可靠的侧向固定，正式翻转使用前须解决防脱，不能靠压紧显示玻璃固定。
- 电池按66.7×37.3×20mm包络布置，底部托槽限位；压条顶面间隙0.5mm，前端从仓内侧穿过挡边通孔，3mm长舌穿过2mm挡边后外露1mm，后端两颗螺丝从后方拧入。舌片与电池约1.3mm名义空隙。短线自由收放，不夹线、不挤压包膜。
- 后盖有2mm定位边，单边名义间隙0.3mm；四角螺丝固定。后盖通气槽并非按原喇叭位置精确匹配的声学设计，实际音量仍需确认。

## 辅料与装配

准备公称直径约3mm、杆长10mm的**塑料用自攻螺钉6颗**：电池压条2颗，后盖4颗。孔是2.5mm导孔，不是M3螺纹孔；不能直接替换为普通M3机牙螺丝。后盖螺丝头直径应≤6.0mm、头高≤2.0mm，适配6.4mm直径、2.2mm深沉台；如实际头型不同须调整沉台。选短头型并先用试样确认，不能用过长螺丝强拧穿底。

1. 所有电子件与电池先取下。清理支撑、毛刺和小孔；在试样上核对螺丝、卡舌配合。槽内若过紧，先修整或改模型，不强压面板。
2. 先用 fit-panel-guide.stl 试插，确认后面板从右侧向左沿上下导轨滑入，干试居中、有效显示区无遮挡，确认USB插头及按键可操作。先仅做静态试装；左侧止挡限制向左滑出，右端防脱仍待完善，取消0.3mm胶条步骤。
3. 电池平放托槽，连接线自由放置，预先确认极性和连接；本模型不改变已有电气接线。
4. 电池和压条在面板移开时先装；先把两个长舌沿通孔插入，配合倾斜动作将后耳落到锚座，从后方拧入两颗螺丝，再安排面板侧插与接线。拆卸先移开面板、后盖并卸压条螺丝，逐步倾斜后退退出长舌；不要平着强拉或强掰。手拧到定位即可，不靠压条压缩电池来固定。第2步的面板试插完成后需先移开，再执行本步。
5. 检查螺丝刀通道、线束空间和电池各方向保持情况；确认后盖定位边完全落入，再拧四颗后盖螺丝。反复翻面确认面板和电池均不移动，按键不会被桌面误压。

## 文件与验证记录

- `*-print.stl` 已按建议方向摆放并落到打印床；只打印这三件正式件。`*-assembly.stl` 是同一几何在装配坐标下的版本，不能与前者重复打印。
- assembly.glb 用于彩色总装查看；preview.png 为从导出网格生成的外观和剖开示意，右图隐藏右半壳并后移后盖，不是一个待打印零件。
- mesh-report.json 记录封闭性、独立实体数、包络、体积、三件之间及其与面板/电池标称包络的相交体积。正式三件均为单一封闭实体，未发现正体积相交；极小负值为浮点数误差。
- 尚未完成：商家切片确认、材料收缩补偿、实际卡舌疲劳与螺纹寿命、面板侧向防脱、翻面牢固性、声学效果和实际线束检查。因此应称为“可切片的首件试制文件”，不称为“已实物验证的最终版”。

## 从源码复现

在项目根目录用 PowerShell：

```powershell
python -m venv .venv-cad
.\.venv-cad\Scripts\python.exe -m pip install -r hardware/enclosure/requirements-cad.txt
.\.venv-cad\Scripts\python.exe hardware/enclosure/build_v12.py
.\.venv-cad\Scripts\python.exe hardware/enclosure/render_v12.py
```

build_v12.py 使用 Manifold 布尔实体直接导出 STL，不依赖 OpenSCAD。V11及更早的 SCAD 保留为历史草案，V12改动不会自动同步到旧SCAD。当前源码固定针对本机实测尺寸；若改面板或电池，需要同步复核槽位、卡舌、螺丝座和打印间隙，不能只修改一个数字。预览脚本使用 Windows 微软雅黑字体；其他平台请替换字体路径，STL生成不受字体影响。
