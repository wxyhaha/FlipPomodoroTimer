# V12.9 打印与装配说明

本项目成品采用嘉立创 X 树脂打印，包含主壳、后盖和电池压条各一件。打印时保持 STL 的毫米单位，不要自动缩放；复制或修改模型后应重新检查配合。

## 模型文件

- [主壳](v12.9/V12.9-shell.stl)
- [后盖](v12.9/V12.9-lid.stl)
- [电池压条](v12.9/V12.9-retainer.stl)
- [打印包](v12.9/print-package-v12-9.zip)

总装设计包络约 90.5×94.5×92.5mm；屏幕面板与电池应以各自实物尺寸为准。主壳、后盖和压条 STL 已检查为单一封闭实体；模型检查不代表打印件实际配合或材料耐久已经验证。

## 装配

1. 清理打印件毛刺，先用实物检查面板槽、接口位置和螺丝孔，不要强压屏幕。
2. 在面板移开时放入电池，先将压条前舌对准挡边通孔，再倾斜安装并从后方固定两颗螺丝；确认压条不挤压电池包膜。
3. 按设计从右侧将面板沿上下导轨滑入，检查线束、接口和按键空间。右侧机械防脱未在模型中单独实现，翻面前须检查实物固定情况。
4. 确认线束没有被压住，合上后盖并固定四角螺丝。拆卸压条前先移开面板、后盖和压条螺丝，逐步倾斜后退，避免强拉。

成品已打印并完成照片所示装配；屏幕防脱、线束受力、反复拆装、螺纹寿命和长期使用仍需验证。模型尺寸与余量见[尺寸表](FINAL-DIMENSIONS-V12.9.md)，成品展示与成本见[项目首页](../../README.md)。
